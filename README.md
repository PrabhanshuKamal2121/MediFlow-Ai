## ✨ Features

- **User Authentication**  
  - Secure login/signup pages (`login.html`)
- **Dashboard**  
  - Admin & staff overview (`dashboard.html`, `dashboard.css`)
- **Hospital & Doctor Management**  
  - List, add, update hospital and doctor records (`hospitals.html`, `doctors.png`)
- **Appointment Manager**  
  - Schedule, reschedule, cancel patient appointments (`appointment-manager.js`, `appointments.html`)
- **Emergency Queue**  
  - Prioritize critical cases & manage emergency slots (`emergency-manager.js`, `styles-emergency.css`)
- **Symptom Checker**  
  - Quick “symptoms and solutions” guide (`symptoms and solutions.txt`)
- **AI‑Chatbot Integration**  
  - Patient–doctor chat powered by Chatbase (`chat.html`, `chatbase-integration.js`, `chat.css`)
- **Real‑time Tracking**  
  - Monitor patient flow & wait times (`tracking.css`, `scripts.js`)
- **Responsive Design**  
  - Mobile‑friendly layouts built with modern HTML5 & CSS3

## 📌 Project Highlights

- **No Backend Required:** Works fully in the browser. Easy to demo or present.
- **AI Chat Integration:** Uses Chatbase to respond to patient queries automatically.
- **Emergency Management:** Prioritizes critical patients via a separate emergency UI.
- **Queue Handling:** Real-time feedback & simulation logic with vanilla JS.
- **Separation of Concerns:** Each section has its own HTML/CSS/JS module.



## 📂 How Files Work

| File | Purpose |
|------|---------|
| `index.html` | Main entry page for users |
| `login.html` | Authentication screen |
| `dashboard.html` | Admin-facing dashboard |
| `appointments.html` | View/manage appointments |
| `emergency.html` | Urgent patient queue |
| `chat.html` | Chatbot interface |
| `scripts.js` | Core logic and interactivity |
| `appointment-manager.js` | Backend logic simulation for appointments |
| `emergency-manager.js` | Emergency queue priority logic |
| `chatbase-integration.js` | Hooks your chatbot to Chatbase API |
| `styles.css` | Global design styling |
| `tracking.css` | Queue animation/tracking specific styles |
| `symptoms and solutions.txt` | Map of symptoms to recommended treatments |
| `/assets/` | Contains images like logo and doctor illustrations |
